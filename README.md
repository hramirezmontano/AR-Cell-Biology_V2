# Biología Celular AR V2

Aplicación interactiva de Realidad Aumentada (AR) desarrollada en Unity diseñada para visualizar y explorar la estructura de una célula vegetal.

##  Características

*  Modelos celulares detallados en tiempo real.
* **Experiencia AR:** Integración con la cámara del dispositivo móvil para proyectar el modelo en entornos reales.

* Tecnologías Utilizadas
* **Motor:** Unity (3D / AR)
* **Lenguaje:** C#
* **Plataforma Objetivo:** Android

---

## Instalación y Demo
1. Dirígete a la sección de **[Releases / Lanzamientos](../../releases)** de este repositorio.
2. Descarga el archivo ejecutable `CelulaVegetalAR_V2.apk`.
3. Instálalo en tu dispositivo Android y ejecuta la aplicación.
